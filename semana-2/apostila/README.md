# 📚 Apostila de Java + Calculadora com POO

> Material de estudo para o grupo — Residência Fullstack

## Como estudar

1. Leia a [APOSTILA_JAVA.md](./APOSTILA_JAVA.md) do início ao fim
2. Digite os exemplos de código você mesmo (não copie, escreva!)
3. Teste e modifique os exemplos para ver o que acontece
4. Pratique o exercício da calculadora

## Estrutura

```
apostila/
├── APOSTILA_JAVA.md          ← Apostila completa (estude aqui!)
└── calculadora/
    ├── Calculadora.java       ← Classe da calculadora (POO)
    └── CalculadoraApp.java    ← Programa principal com menu
```

## Como rodar a calculadora

```bash
# Entre na pasta
cd calculadora/

# Compile os dois arquivos
javac Calculadora.java CalculadoraApp.java

# Execute
java CalculadoraApp
```
