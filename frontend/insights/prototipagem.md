## Decisões de Design

| Elemento | Decisão |
|---------|---------|
| **Tema** | Dark Mode total |
| **Background** | `#111113` (grafite quase preto) |
| **Accent principal** | `#00BCD4` (ciano tech) |
| **Texto principal** | `#FFFFFF` |
| **Texto secundário** | `#A0A0A5` (cinza) |
| **Fonte** | Inter (Google Fonts) |
| **Layout** | Full-page sections (scroll por seção) |
| **Navbar** | Logo VM à esquerda + botão Contato à direita |
| **Paginação** | Numeração vertical direita: 00 → 04 |

---

## Estrutura de Seções

```
00 → Hero       (Apresentação + CTA)
01 → Sobre      (Bio + foto)
02 → Skills     (Grid de tecnologias)
03 → Projetos   (Slider de cards)
04 → Contato    (Links + email)
```

---

## Seção 00 — Hero

**Layout:** 2 colunas (texto esquerda | visual direita)

- Esquerda: nome/cargo em grande + tagline + 2 botões CTA
- Direita: avatar/ilustração tech
- Accent color: ciano nos botões primários

---

## Seção 03 — Projetos (Slider)

**Layout:** Slider com dots de navegação

- Texto/contexto à esquerda
- Mockup de device à direita
- Alternância de lado a cada projeto (dinâmica visual)
- Tags de tecnologias como pills
